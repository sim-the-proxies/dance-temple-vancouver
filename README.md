# Dance Temple Vancouver website prototype

Open `index.html` in a browser. No build step or framework is required.

## Before launch

- Replace the two placeholder dates in `index.html` and the matching event page.
- Replace `href="#"` ticket links with the real ticket URLs.
- Connect the contact form to a form service or site backend. It currently opens the visitor's email app.
- Confirm addresses, accessibility information, age policy, ticket policy and event copy.
- Optimise `assets/dancers-hero.png` to WebP/AVIF if desired.

The generated dancer photograph is original AI-created imagery. Event poster art is HTML/CSS, so all important event text remains accessible and easy to update.
